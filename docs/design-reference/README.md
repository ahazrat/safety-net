# Design reference

Mockups and mood-board imagery from the project's earliest days (2020,
originally in a separate `agorapolis` folder — no code, just images, folded
in here during the monorepo consolidation). Not consumed by any app code;
kept as product-vision reference.

- `agora-mission-illustration.jpeg` — illustration of the ancient Athenian
  agora/polis, referenced by the project's name and mission statement.
- `map-listing-pin-mockup.png` — early concept for a listing pin on the map
  (matches `apps/web/src/pages/Map.js`'s marker/popup pattern).
- `live-tracking-mockup.png` — early concept for live-tracking a security
  escort's route between waypoints on a map.
